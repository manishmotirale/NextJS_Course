## ✨ About This Repository

This repository documents my **Next.js learning journey** through structured modules, hands-on experiments, mini-projects, and larger full-stack applications.

Instead of only following tutorials, the goal is to **learn a concept and immediately build with it**.

> 💡 **Every module = a concept + implementation + practical project**

The course progresses from Next.js fundamentals to advanced full-stack concepts such as authentication, databases, payments, caching, and real-world application clones.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/manishmotirale/NextJS_Course.git
cd NextJS_Course
```

### 2. Choose a project

For example:

```bash
cd "1.Getting Started/mini-project"
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start development

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```

> ⚠️ Each project can have different dependencies and scripts. Always check its `package.json` before running it.

## 🔐 Environment Variables

Some projects may require API keys or environment variables for:

- Databases
- Authentication
- Payments
- Supabase
- Convex
- External APIs

**Never commit secrets to GitHub.**

Keep files such as `.env`, `.env.local`, and other secret configuration files out of version control.
